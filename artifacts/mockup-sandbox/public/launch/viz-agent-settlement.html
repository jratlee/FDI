Field Guide 003 · Crypto primitives for agent commerce

Three open primitives. Agents settle in crypto, no human in the loop.

01 / Mandate
AP2
Payment mandate
User pre-authorizes agent to spend within defined limits: max amounts, approved counterparties, permitted transaction types.

02 / Payment
x402
HTTP-native USDC payment
API returns 402 with payment terms. Agent pays inline in the HTTP request using stablecoin on Base. No billing accounts, no subscriptions.
coinbase/x402 · MIT
wallet transacts
03 / Wallet
AgentKit
Managed agent wallet
Agent holds a managed Ethereum wallet, sends transactions, calls smart contracts, checks balances — all within its task loop.
