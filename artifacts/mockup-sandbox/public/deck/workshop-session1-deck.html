Reference · 09/13
Grade It

What should a machine trust?

Tier 1
Own it.
First-party, named, dated, verifiable. You control the provenance.
Tier 2
Corroborated.
Independent, evidence shown. Someone else can verify the claim.
Tier 3
Noise.
Optimized to rank, not to be true. Avoid building on Tier 3.
