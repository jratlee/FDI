Process · 07/12
Loop engineering · after LangChain and Addy Osmani

Four loop levels: from task runner to self-improving harness

LEVEL 1

Agent Loop

One model calls tools until a discrete task completes. Automates isolated, high-volume work.

LEVEL 2

Verification Loop

Output scored against a strict rubric; failures retry with feedback. Brand safety, compliance, factual checks.

LEVEL 3

Event-Driven Loop

External signals trigger runs. Responsive market action without a human initiating.

LEVEL 4

Hill-Climbing Loop

The system studies its own production traces and improves prompts, models, and memory over time.

Process · 08/12
Governance as infrastructure

The river needs a riverbank. Prompts are not controls.

Contain

Blast radius at the OS level

Scope agent permissions at the container or operating system layer, not the runtime. What an agent cannot reach, it cannot break.

Compile

Policy as code

Brand rules, legal limits, and budgets become executable boolean conditions (Open Policy Agent is the common engine). Violations block instantly, no ticket queue.

Record

Log intent, not just action

Forensics in a non-deterministic world means knowing what the agent tried and why, including what the policy layer refused.

The plan · 11/12
A CMO's first 90 days

Assess, pilot, scale. Protect the base the whole way.

Days 1-30

Assess and contain

Map your org's real shape. Freeze middle-heavy hiring. Pull two or three latent polymaths into a pod. Stand up policy as code before agents touch production.

Days 31-60

Pilot loops and proof

Ship the Verification Loop first, then an SEO/GEO loop with automated rollback. Re-sequence every pending campaign around the Proof Stack.

Days 61-90

Scale pods, build the base

Move to pods plus platform. Retrain teams on citation authority. Launch the sandboxed junior program. Leaders keep maker time on the calendar.
