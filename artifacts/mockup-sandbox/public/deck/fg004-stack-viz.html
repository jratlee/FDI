Field Guide 004 · Autonomous · The open agent commerce stack

MCP → A2A → AP2 → x402: four layers, all Apache-licensed, all shipping now

Layer 1 · Tools & Data
MCP
Model Context Protocol

Exposes any system as agent-callable tools, resources, and prompts over JSON-RPC 2.0. The layer at which a brand becomes something an agent can invoke.

97M+ monthly SDK downloads · 10,000+ public servers · Agentic AI Foundation (Linux Foundation)
Layer 2 · Agent Coordination
A2A
Agent2Agent Protocol

Agents discover and delegate to other agents at runtime via Agent Cards — without pre-wired integrations. The layer at which your agent becomes findable to a buyer's agent.

150+ orgs · stable 1.0 · production use in supply chain, finance, insurance · Linux Foundation
Layer 3 · Payment Auth
AP2
Agent Payments Protocol

Cryptographically signed "mandates" built on W3C Verifiable Credentials prove a human authorized the transaction. Runs as an extension of both A2A and MCP.

Google · 60+ partners: Mastercard, Amex, PayPal, Coinbase, Worldpay · Sep 2025
Layer 4 · Settlement
x402
Stablecoin settlement rail

HTTP-native micropayments settled in stablecoins (USDC) via Coinbase x402 + agentkit. The crypto throughline: agents settle trades without touching wire-transfer systems.

Coinbase · Apache 2.0 · connects to the Decentralized Field Guide
