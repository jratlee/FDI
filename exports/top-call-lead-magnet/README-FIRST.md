# Top Call — Copilot / Claude Co-work Install Package

> **A False Dawn Industries Field Guide companion — the free prompt-pack.**
> New here? Read `00-START-HERE-FDI.md` first. It explains why we give this away,
> and what the paid owned system (`falsedawn.industries/topcall`) does that a
> prompt-pack structurally cannot: compound a graded, provenance-stamped corpus
> you own, instead of producing a disposable brief every run.

This package installs **Top Call**, a repeatable executive-briefing workflow for Microsoft Copilot and Claude Co-work-style workspaces.

Top Call helps you turn trusted articles, newsletters, reports, and local files into a concise executive brief with:

- a clear **Top Call**
- TLDR bullets
- validated source links
- executive moves
- “so what” implications
- a watchlist for next week
- a source log with paywall/access notes

## What to install first

Start with these two files:

1. `INSTALL-ELI5.md` — simple setup walkthrough.
2. `COPILOT-AGENT-INSTRUCTIONS.md` — paste this into Copilot/Copilot Studio or your Claude Co-work workstation instructions.
