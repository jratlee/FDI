Top Call started life as a portable executive-briefing workflow: a set of

workstation. Point it at a folder of trusted sources and it drafts a weekly
executive intelligence brief — a clear *Top Call*, TLDR, validated sources,
executive moves, "so what" implications, a watchlist, and a source log.

It works. Install it, use it, keep it. Everything in this bundle is yours.

## What a prompt-pack can — and cannot — do

A prompt-pack is a *recipe*. Anyone with the same prompts and the same public
web gets roughly the same brief. Each run starts from a blank page and produces a
**disposable** artifact — a rented outcome. Nothing compounds:

- The grading you do this week (which sources were Tier 1, which were vendor SEO
  noise, which executive move was corroborated) evaporates when the chat ends.
- Next week you re-audit the same publications from scratch.
- No two runs share a memory, so the brief never gets *smarter* — only newer.
- An agent cannot call it, verify where a claim came from, or cite it.

The prompts are replicable. **The recipe is not the moat.**

The paid Top Call is the *inbound sibling to Skillfoundry* — **Signal as Code,

makes them durable:

- **Aggregated → a citable corpus.** Every source you grade is written into a

- **Decentralized → a knowledge graph.** Executives, companies, moves,

The non-replicable asset is **not** the prompts in this folder. It is the
