# The Davos Decision Kit

A self-serve decision system for executives and comms leaders who are Davos
Curious: weighing whether the World Economic Forum annual meeting belongs on
next January's calendar, and what it would take to make the week count.

## What is inside

| File | What it does |
| --- | --- |
| `go-no-go-scorecard.md` | A weighted decision framework that produces a board-defensible go or no-go recommendation |
| `twelve-month-runway.md` | The month-by-month plan, working backward from the January week |
| `budget-calculator.md` | A cost worksheet with realistic public-range estimates so you price the trip before you commit |
| `visibility-plan-templates.md` | Meeting-request scripts, a briefing-doc template, a model high-impact week, and the follow-up system |

## How to use the kit

1. Run the **Go/No-Go Scorecard** first. It takes about 45 minutes with the
   right people in the room. If the score says no, you just saved a six-figure
   week and you are done.
2. If the score says go, open the **Budget Calculator** and produce the number
   you will defend internally.
3. Put the **Twelve-Month Runway** into your calendar the same day. Davos
   outcomes are decided months before the week begins.
4. Use the **Visibility Plan Templates** to build the meeting stack and the
   follow-up system.
