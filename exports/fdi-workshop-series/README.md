# The Cartographers' Table

**A recurring in-person workshop series from False Dawn Industries · Growth Cartography**

> Aggregated · Decentralized · Autonomous

This folder is the complete facilitator kit for **The Cartographers' Table**, a
repeatable in-person workshop FDI can run again and again to generate qualified
SkillFoundry leads, establish thought leadership on the *owned marketing systems*
thesis, send every attendee home with a hands-on skill, and validate the thesis
against a live audience.

## The concept in one line

Marketing strategists gather around a table to **map new territory and leave
having built a piece of an owned system they keep** — because a map you draw
yourself is worth more than a map you rent.

The series *is* the thesis. Come to one session and you leave with a useful but
disposable artifact (a rented outcome, like the free prompt-pack). Come to the
whole season and each session compounds onto the last until you have built the
beginnings of an owned system (a corpus, a graph, an interface) that no one can
take away. That compounding-versus-evaporating contrast is exactly the argument
in *Build the Machine, Not the Ad*, made physical in a room.

## Who it is for

One primary audience, decided by design-thinking in `01-audience-decision.md`:
**AI-forward fractional CMOs and independent B2B marketing / growth strategists**
(solo or 1 to 15 person practices serving SaaS and tech). This is the same
beachhead the SkillFoundry Tier 1 motion already targets, so the room, the pitch,
and the funnel all point the same direction.

## How to run it (fast path for a facilitator)

1. Read `01` and `02` once to internalize the audience and the arc.
2. For each event, work from `03` (the run-of-show) with `04` printed for the room.
3. Set up capture from `05` before the doors open (QR to the waitlist, tag set).
4. Run the feedback loop from `06` in the last 10 minutes, every time.
5. Re-skin slides per session using `07`.

## Scope note

This kit is documents only. Booking venues, setting dates, procurement, printing,
and building a dedicated event-registration page are deliberately out of scope.
Lead capture reuses the site's existing `/api/waitlist` flow (see `05`); wiring a
bespoke registration page can be a later task.
